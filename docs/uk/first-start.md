## 1. Отримання та перевірка інсталятора FirstInstall

1. Відкрийте [випуск v0.12.0-alpha в розділі Releases](https://github.com/nikolaykazakovvs-ux/golden-breeze-releases/releases/tag/v0.12.0-alpha) та ознайомтеся з нотатками до випуску. (Для попередніх `alpha`-випусків використовуйте пряме посилання на тег або сторінку Releases, оскільки адреса `/releases/latest` у GitHub не включає `pre-release`.)
2. Завантажте автономний інсталятор **[GoldenBreeze-FirstInstall-0.12.0-alpha.exe](https://github.com/nikolaykazakovvs-ux/golden-breeze-releases/releases/download/v0.12.0-alpha/GoldenBreeze-FirstInstall-0.12.0-alpha.exe)** (`383 300 782` байт / `365,5 МіБ`) і файл контрольної суми **[GoldenBreeze-FirstInstall-0.12.0-alpha.exe.sha256](https://github.com/nikolaykazakovvs-ux/golden-breeze-releases/releases/download/v0.12.0-alpha/GoldenBreeze-FirstInstall-0.12.0-alpha.exe.sha256)**.
   - *Примітка:* архіви `Source code (zip / tar.gz)`, що автоматично створюються GitHub, містять лише файли інформаційної вітрини та не є інсталятором програми.
3. Перед запуском перевірте контрольну суму `SHA-256` у Windows PowerShell (вона підтверджує побайтовий збіг завантаженого файлу з довіреним артефактом випуску):

```powershell
Get-FileHash .\GoldenBreeze-FirstInstall-0.12.0-alpha.exe -Algorithm SHA256
```

Еталонне значення `SHA-256` для `v0.12.0-alpha`:
`d4546bc1fe718020f78315bbe98e4b232db044fb80bdb1061f1d2fe44ffd60a2`

4. **Підпис виконуваного файлу та захисник Windows:**
   - Виконуваний файл `.exe` наразі не підписаний платним сертифікатом видавця Windows **Authenticode** (його купівлю відкладено до виходу продукту на прибуток).
   - Тому під час першого запуску інсталятора Windows SmartScreen може показати попередження про невідомого видавця. Якщо контрольна сума `SHA-256` збігається, підтвердьте запуск вручну: **«Докладніше» → «Виконати в будь-якому разі»**.
   - На системах Windows 11 з увімкненим режимом *Smart App Control* ручний обхід для непідписаних файлів системою не передбачено — рішення про вимкнення цього режиму користувач ухвалює самостійно.

## 2. Підготовка робочого простору

- **Вбудоване середовище:** інсталятор `FirstInstall` містить власний runtime і не потребує окремого встановлення Python, Node.js або Git.
- **Мова інтерфейсу:** у верхній панелі вікна доступний вибір мови — **RU** (російська), **UA** (українська) або **EN** (англійська). Обрана мова зберігається під час перезапуску й оновлення.
- **Провайдери ШІ та рахунки:** у розділі **Налаштування** підключіть обраного провайдера моделей ШІ (в опублікованому випуску `v0.12.0-alpha` діалог головного агента працює через Claude CLI, а вхід через Codex CLI / ChatGPT у Налаштуваннях уже підтримується і стає повнофункціональним ядром головного діалогу в циклі `0.13–0.14-alpha`) і за потреби налаштуйте підключення до встановленого торгового термінала **MetaTrader 5 (MT5)**. Не передавайте програмі SSH-ключі, токени GitHub або секрети розробника.
- **Перевірка типу рахунку та прав виконання:** платформа підтримує як демо (`Demo`), так і реальні (`Real`) рахунки MT5. Під час підключення рахунку програма отримує його тип і параметри від торгової платформи, а під час входу до кабінету проп-компанії (у поточному контурі — FTMO) пов'язує правила ризику з рахунком.
- **Торговий цикл у Пульті керування:**
  **вибір профілю агента і рахунку → `Вивчити ринок` → `Перевірити готовність` → `Запустити торгівлю` → супровід позицій у межах лімітів ризику → `Зупинити`**.
  - Саме встановлення або запуск програми ніколи не відкриває угоди автоматично; під час активної сесії агент діє в межах призначеної стратегії та лімітів ризику під контролем користувача.
  - Якщо кнопка неактивна (наприклад, закритий ринок, немає свіжого тіка брокера або в терміналі MT5 вимкнено *Algo Trading*), Пульт указує конкретну причину та крок для її усунення (у циклі `0.13–0.14-alpha` для наступного випуску також додано фоновий прогрів перевірки годинника брокера й автоматичну синхронізацію історії символу в «Огляді ринку»).

## 3. Автооновлення за кнопкою (канал stable)

1. Після первинного встановлення `FirstInstall` подальші оновлення каналу `stable` доставляються напряму з власного захищеного HTTPS-сервера Golden Breeze (доступ до GitHub для оновлень не потрібен).
2. Програма перевіряє криптографічний підпис маніфесту оновлення (**Ed25519**, файл `.sig`) і контрольні суми пакетів. Коли пакет готовий, з'являється банер: *«Нову версію завантажено. Після оновлення застосунок відкриється автоматично.»* із кнопкою **«Оновити зараз»**.
3. Перехід виконується в три кроки: **«Підготовка → Оновлення → Запуск»**. Якщо активне робоче ядро агента або триває операція, програма чекає на безпечне завершення. Якщо теку програми утримує сторонній процес, вікно оновлення покаже його ім'я та продовжить встановлення після звільнення теки.
4. Користувацькі профілі, рахунки та видима історія діалогів зберігаються. У разі збою оновлення програма відновлює попередню версію та формує короткий знеособлений технічний звіт (без шляхів з ім'ям користувача, номерів рахунків, ключів і вмісту баз).
