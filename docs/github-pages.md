# Памятка по публикации витрины на GitHub Pages (`docs/github-pages.md`)

**Актуализация: 25 октября 2026 года.** В каталоге `docs/` подготовлен статический лендинг продукта Golden Breeze (`docs/index.html`, `docs/styles.css`, `docs/app.js`, `docs/assets/`, `docs/.nojekyll`), предназначенный для публичной публикации через **GitHub Pages** в репозитории витрины и релизов `nikolaykazakovvs-ux/golden-breeze-releases`.

Целевой публичный адрес витрины при включении GitHub Pages:
- `https://nikolaykazakovvs-ux.github.io/golden-breeze-releases/`

*(Фактическое включение публикации и проверка доступности адреса выполняются на этапе интеграции ветки в `main`.)*

---

## 1. Устройство статического лендинга в `docs/`

Лендинг реализован на чистом HTML, CSS и компактном JavaScript без сборщиков, сторонней аналитики и внешних CDN:

- **Точка входа:** `docs/index.html`
- **Стили и адаптивность:** `docs/styles.css` (поддержка десктопа, планшетов и мобильных экранов, компактное меню навигации при `<= 1024px`, учёт `scroll-padding-top` для фиксированной шапки и `prefers-reduced-motion`).
- **Интерактивность:** `docs/app.js` (мобильное меню навигации, фильтрация направлений дорожной карты по статусам и копирование `SHA-256` / команды PowerShell).
- **Отключение Jekyll:** пустой файл `docs/.nojekyll` гарантирует прямую раздачу статических файлов без перезаписи путей генератором Jekyll.
- **Ссылки на документацию:** поскольку при включённом `.nojekyll` прямые переходы на `.md`-файлы внутри GitHub Pages открывают необработанный текст, ссылки из HTML-лендинга на подробные документы (`roadmap.md`, `first-start.md`, `github-pages.md`) ведут на отрисованные страницы GitHub (`blob/main/docs/...`). Все локальные медиа-ресурсы (`./styles.css`, `./app.js`, `./assets/...`) подключены относительными путями и одинаково работают локально и по проектному префиксу `/golden-breeze-releases/`.

---

## 2. Настройка публикации из `main:/docs`

Публикация витрины настраивается штатным механизмом GitHub без создания отдельных GitHub Actions workflows:

1. Репозиторий витрины и раздачи `nikolaykazakovvs-ux/golden-breeze-releases` переводится в публичный режим (`Public`), чтобы посетители могли открывать витрину, читать документацию и напрямую скачивать установщик `FirstInstall` из раздела `Releases` (основной репозиторий разработки ядра остаётся отдельным и закрытым).
2. В настройках репозитория **Settings → Pages** в блоке **Build and deployment** выбирается:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`, папка `/docs` → **Save**.
3. После завершения развёртывания проверяется открытие страницы по адресу `https://nikolaykazakovvs-ux.github.io/golden-breeze-releases/` и работа ссылок на текущий выпуск `v0.12.0-alpha`.

## 3. Локальный предпросмотр

Для локальной проверки вёрстки из корня репозитория используется стандартный HTTP-сервер на локальном интерфейсе (`127.0.0.1`):

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory docs
```

Локальный адрес предпросмотра: `http://127.0.0.1:8765/`.
