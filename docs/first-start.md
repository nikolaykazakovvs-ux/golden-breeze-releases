## 1. Получение и проверка установщика FirstInstall

1. Откройте [выпуск v0.14.0-alpha в разделе Releases](https://github.com/nikolaykazakovvs-ux/golden-breeze-releases/releases/tag/v0.14.0-alpha) и ознакомьтесь с заметками к выпуску. (Для предварительных `alpha`-выпусков используйте прямую ссылку на тег или страницу Releases, так как адрес `/releases/latest` в GitHub не включает `pre-release`.)
2. Скачайте автономный установщик **[GoldenBreeze-FirstInstall-0.14.0-alpha.exe](https://github.com/nikolaykazakovvs-ux/golden-breeze-releases/releases/download/v0.14.0-alpha/GoldenBreeze-FirstInstall-0.14.0-alpha.exe)** (`406 722 870` байт / `387,9 МиБ`) и файл контрольной суммы **[GoldenBreeze-FirstInstall-0.14.0-alpha.exe.sha256](https://github.com/nikolaykazakovvs-ux/golden-breeze-releases/releases/download/v0.14.0-alpha/GoldenBreeze-FirstInstall-0.14.0-alpha.exe.sha256)**.
   - *Примечание:* архивы `Source code (zip / tar.gz)`, автоматически создаваемые GitHub, содержат только файлы информационной витрины и не являются установщиком программы.
3. Перед запуском проверьте контрольную сумму `SHA-256` в Windows PowerShell (она подтверждает побайтовое совпадение скачанного файла с доверенным артефактом выпуска):

```powershell
Get-FileHash .\GoldenBreeze-FirstInstall-0.14.0-alpha.exe -Algorithm SHA256
```

Эталонное значение `SHA-256` для `v0.14.0-alpha`:
`f166f00d4bbfd5e299c7f52e9ba3b51c3c208ea1d9f3b93dbc039806e113d69e`

4. **Подпись исполняемого файла и защитник Windows:**
   - Исполняемый файл `.exe` сейчас не подписан платным сертификатом издателя Windows **Authenticode** (его покупка отложена до выхода продукта на прибыль).
   - Поэтому при первом запуске установщика Windows SmartScreen может показать предупреждение о неизвестном издателе. При совпадении контрольной суммы `SHA-256` подтвердите запуск вручную: **«Подробнее» → «Выполнить в любом случае»**.
   - На установках Windows 11 с включённым режимом *Smart App Control* ручной обход для неподписанных файлов системой не предусмотрен — решение об отключении этого режима пользователь принимает самостоятельно.

## 2. Подготовка рабочего пространства

- **Встроенное окружение:** установщик `FirstInstall` включает собственный runtime и не требует отдельной установки Python, Node.js или Git.
- **Язык интерфейса:** в верхней панели окна доступен выбор языка — **RU** (русский), **UA** (украинский) или **EN** (английский). Выбранный язык сохраняется при перезапуске и обновлении.
- **Провайдеры ИИ и счета:** в разделе **Настройки** подключите выбранного провайдера моделей ИИ (в выпуске `v0.14.0-alpha` диалог главного агента полноценно работает как через **Claude CLI**, так и через **Codex CLI / вход через ChatGPT без API-ключа**) и при необходимости настройте подключение к установленному торговому терминалу **MetaTrader 5 (MT5)** (доступен переключатель **«Подключить сейчас»**, автовыбор адаптера по семейству платформы и автоподготовка выделенного терминала MT5). Не передавайте программе SSH-ключи, токены GitHub или секреты разработчика.
- **Проверка типа счёта и прав исполнения:** платформа поддерживает подключение как демо (`Demo`), так и реальных (`Real`) счетов MT5. При подключении счёта программа получает его тип и параметры от торговой платформы, а при входе в кабинет проп-компании (в текущем контуре — FTMO) связывает правила риска со счётом. Специальное ограничение «только демо-счёт» действует исключительно для диагностического тестового маршрута, тогда как для работы с подключённым `Real`-счётом граница состоит в том, что живая приёмка `v0.14.0-alpha` проведена на `FTMO-Demo` и завершённая живая торговая приёмка на счёте `Real` не заявляется.
- **Торговый цикл в Пульте управления:**
  **выбор профиля агента и счёта → `Изучить рынок` → `Проверить готовность` → `Запустить торговлю` → сопровождение позиций в рамках лимитов риска → `Остановить`**.
  - Сама установка или запуск программы никогда не открывает сделки автоматически; в ходе запущенной сессии агент действует в рамках назначенной стратегии и риск-лимитов под контролем пользователя.
  - Если кнопка неактивна (например, закрыт рынок, нет свежего тика брокера или в терминале MT5 выключен *Algo Trading*), Пульт указывает конкретную причину и шаг для её устранения (в `v0.14.0-alpha` также работают немедленный анализ закрытых баров кнопкой **«Изучить рынок»** при закрытом рынке, фоновый прогрев часов брокера и автоматическое добавление инструмента в «Обзор рынка» MT5 с ожиданием синхронизации истории).

## 3. Автообновление по кнопке (канал stable)

1. После первоначальной установки `FirstInstall` дальнейшие обновления канала `stable` доставляются напрямую с собственного защищённого HTTPS-сервера Golden Breeze (доступ к GitHub для обновлений не нужен).
2. Программа проверяет криптографическую подпись манифеста обновления (**Ed25519**, файл `.sig`) и контрольные суммы пакетов. Когда пакет готов, появляется баннер: *«Новая версия загружена. После обновления приложение откроется автоматически.»* с кнопкой **«Обновить сейчас»**.
3. Переход выполняется в три шага: **«Подготовка → Обновление → Запуск»**. Если активно рабочее ядро агента или идёт операция, программа дожидается безопасного завершения. Если папку программы удерживает сторонний процесс, окно обновления покажет его имя и продолжит установку после освобождения папки.
4. Пользовательские профили, счета и видимая история диалогов сохраняются. При сбое обновления программа восстанавливает предыдущую версию и формирует короткий обезличенный технический отчёт (без путей с именем пользователя, номеров счетов, ключей и содержимого баз).
