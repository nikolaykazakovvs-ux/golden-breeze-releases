# Установка и первый запуск

**Язык / Мова / Language:** **Русский** · [Українська (docs/uk/first-start.md)](./uk/first-start.md) · [English (docs/en/first-start.md)](./en/first-start.md)

**Состояние на 26 ноября 2026 года** (доступный выпуск в канале `stable` опубликован 26.11.2026; размер, SHA-256 и подпись манифеста первичной установки сверены 26.11.2026). В разделе Releases опубликован предварительный выпуск **`v0.20.0-alpha`** (канал `stable`, пакет первичной установки **`FirstInstall`** для Windows 10/11 x64). На базе возможностей `0.13.0-alpha`–`0.16.0-alpha` (каталог стратегий, единый Пульт, расширенные рыночные данные, проверка сигналов Replay — не бэктест, окно «О программе» и диагностический отчёт) выпуски `0.17` добавляют выбор подключённых CLI-, API-ядер ИИ и локальной Ollama в чате с разделённым меню «Ядро / Модель / Мышление», категории памяти решений с журналом работы бота, допуск для FTMO без ручного ревью поведения, упорядоченный Пульт с подключением MT5 по требованию и отдельной аварийной остановкой ядра, а также фоновые вызовы CLI без вспышек окон. `v0.17.3` добавляет показ баланса и эквити подключённого счёта в Пульте, кнопку «Создать API-ключ», открывающую официальную страницу провайдера, обновление списка моделей для API-провайдеров и Ollama и исправление Claude API в чате и торговом цикле. `v0.18` добавляет параллельные торговые циклы нескольких агентов с собственными снимками счетов, общий контроль риска счёта, отдельные фоновые экземпляры MT5 для каждого счёта и закреплённую панель запущенных агентов; управление портфелем и капиталом остаётся запланированным. v0.18.1 исправляет: платные этапы проверки FTMO корректно распознаются при чтении кабинета, а окно входа отличает страницу ошибки провайдера от сбоя сети; обычная «Остановка», запрошенная во время запуска агента, больше не теряется и завершается только после того, как агент подтвердит чистый выход без открытых позиций; настройки и диагностика провайдеров доступны, пока открытые позиции сопровождаются защитой; карточки стратегий показывают фактическое число пройденных проверок и точное имя версии. `v0.19` добавляет графический Пульт: живой график свечей из терминала MT5 с линиями применяемой стратегии, отметками сигналов, решений ядра ИИ и подтверждённых брокером сделок, линиями открытой позиции, разбором решения «Стратегия → Ядро → Брокер», карточками «Живая котировка», «Контекст рынка и сессии» и «Лента событий»; график читает инструменты, видимые в «Обзоре рынка» терминала. `v0.19.1` исправляет доставку брокеру ордеров агентов, привязанных к счёту, и проверку режима счёта, подключённого через собственный фоновый процесс. `v0.19.2` — исправительный выпуск без новых возможностей: он заставляет проверку возможностей счёта читать счёт, подключённый через собственный фоновый процесс, обновляет проверку типа и подпись счёта после переподключения, учитывает резерв комиссии при повторной проверке риска, показывает в живом графике расчёт стратегии пользователя и привязывает «Служебные проверки» и разрешение на исполнение к выбранному агенту. `v0.20.0` — выпуск без новых возможностей для пользователя: он исправляет карточку источника под ответом чата (она указывает на ту часть документа библиотеки, которую агент действительно прочитал, найденное поиском, но не открытое агентом показано отдельно, а ранее сохранённые ответы показываются как были сохранены) и содержит только серверную часть симулятора бумажной торговли; режима бумажной торговли в программе пока нет. Отдельный выпуск `v0.19.0` клиентам не публиковался: после `0.18.1` следующий клиентский выпуск — `0.19.1`. Акт живой приёмки `v0.20` на витрине не опубликован; проверки установки, обновления и демо-сделок на `FTMO-Demo` от 12.11.2026 относятся к прежнему установщику `v0.14.0-alpha`.

## 1. Получение и проверка установщика FirstInstall

1. Откройте [выпуск v0.20.0-alpha в разделе Releases](https://github.com/nikolaykazakovvs-ux/golden-breeze-releases/releases/tag/v0.20.0-alpha) и ознакомьтесь с заметками к выпуску. (Для предварительных `alpha`-выпусков используйте прямую ссылку на тег или страницу Releases, так как адрес `/releases/latest` в GitHub не включает `pre-release`.)
2. Скачайте автономный установщик **[GoldenBreeze-FirstInstall-0.20.0-alpha.exe](https://github.com/nikolaykazakovvs-ux/golden-breeze-releases/releases/download/v0.20.0-alpha/GoldenBreeze-FirstInstall-0.20.0-alpha.exe)** (`407 647 786` байт / `388,8 МиБ`) и файл контрольной суммы **[GoldenBreeze-FirstInstall-0.20.0-alpha.exe.sha256](https://github.com/nikolaykazakovvs-ux/golden-breeze-releases/releases/download/v0.20.0-alpha/GoldenBreeze-FirstInstall-0.20.0-alpha.exe.sha256)**.
   - *Примечание:* архивы `Source code (zip / tar.gz)`, автоматически создаваемые GitHub, содержат только файлы информационной витрины и не являются установщиком программы.
3. Перед запуском проверьте контрольную сумму `SHA-256` в Windows PowerShell (она подтверждает побайтовое совпадение скачанного файла с доверенным артефактом выпуска):

```powershell
Get-FileHash .\GoldenBreeze-FirstInstall-0.20.0-alpha.exe -Algorithm SHA256
```

Эталонное значение `SHA-256` для `v0.20.0-alpha`:
`5ffdb08fc824bc336387be4b6c718fea6853dc11976bed9da51dde0c3d9299c4`

4. **Подпись исполняемого файла и защитник Windows:**
   - Исполняемый файл `.exe` сейчас не подписан платным сертификатом издателя Windows **Authenticode** (его покупка отложена до выхода продукта на прибыль).
   - Поэтому при первом запуске установщика Windows SmartScreen может показать предупреждение о неизвестном издателе. При совпадении контрольной суммы `SHA-256` подтвердите запуск вручную: **«Подробнее» → «Выполнить в любом случае»**.
   - На установках Windows 11 с включённым режимом *Smart App Control* ручной обход для неподписанных файлов системой не предусмотрен — решение об отключении этого режима пользователь принимает самостоятельно.

## 2. Подготовка рабочего пространства

- **Встроенное окружение:** установщик `FirstInstall` включает собственный runtime и не требует отдельной установки Python, Node.js или Git.
- **Язык интерфейса:** в верхней панели окна доступен выбор языка — **RU** (русский), **UA** (украинский) или **EN** (английский). Выбранный язык сохраняется при перезапуске и обновлении.
- **Провайдеры ИИ и счета:** в разделе **Настройки** подключите выбранного провайдера моделей ИИ (в выпуске `v0.20.0-alpha` диалог главного агента работает на любом подключённом и включённом ядре: **Claude CLI**, **Codex CLI / вход через ChatGPT без API-ключа**, **Antigravity CLI**, **Kimi CLI**, API **OpenAI**, **Claude**, **Gemini** и **OpenRouter** или локальная **Ollama**; ключи API хранятся в системном хранилище; кнопка «Создать API-ключ» лишь открывает официальную страницу провайдера, а «Обновить модели» получает актуальный список моделей) и при необходимости настройте подключение к установленному торговому терминалу **MetaTrader 5 (MT5)** (доступен переключатель **«Подключить сейчас»**, автовыбор адаптера по семейству платформы и автоподготовка выделенного терминала MT5). Не передавайте программе SSH-ключи, токены GitHub или секреты разработчика.
- **Проверка типа счёта и прав исполнения:** платформа поддерживает подключение как демо (`Demo`), так и реальных (`Real`) счетов MT5. При подключении счёта программа получает его тип и параметры от торговой платформы, а при входе в кабинет проп-компании (в текущем контуре — FTMO) связывает правила риска со счётом. Специальное ограничение «только демо-счёт» действует исключительно для диагностического тестового маршрута, тогда как для работы с подключённым `Real`-счётом граница состоит в том, что исторически живая приёмка `v0.14.0-alpha` проведена на `FTMO-Demo` (акт для `v0.20.0-alpha` на витрине не опубликован) и завершённая живая торговая приёмка на счёте `Real` не заявляется.
- **Торговый цикл в Пульте управления:**
  **выбор профиля агента и счёта → `Разовый разбор рынка (без сделок)` → `Подготовить к запуску` → `Запустить торговлю` → сопровождение позиций в рамках лимитов риска → `Остановить`**.
  - Сама установка или запуск программы никогда не открывает сделки автоматически; в ходе запущенной сессии агент действует в рамках назначенной стратегии и риск-лимитов под контролем пользователя.
  - **«Остановить»** прекращает только новые входы: открытые позиции сохраняют защиту и `trailing-stop`, пока брокер не подтвердит, что их не осталось, а остановка, запрошенная во время запуска агента, не теряется; настройки провайдеров в это время доступны. Закрытие позиций — отдельное действие. **Аварийная остановка ядра** — отдельный блок с двухшаговым подтверждением: она немедленно останавливает ядро, включая наблюдение за `trailing-stop`, при этом уже выставленные у брокера стоп-лосс и тейк-профит сохраняются; позиции она не закрывает.
  - Если кнопка неактивна (например, закрыт рынок, нет свежего тика брокера или в терминале MT5 выключен *Algo Trading*), Пульт указывает конкретную причину и шаг для её устранения внутри панели действий (в `v0.20.0-alpha` счёт MT5 из «Настроек» подключается по требованию при подготовке к запуску или разовом разборе рынка; также работают немедленный анализ закрытых баров кнопкой **«Разовый разбор рынка (без сделок)»** при закрытом рынке, фоновый прогрев часов брокера и автоматическое добавление инструмента в «Обзор рынка» MT5 с ожиданием синхронизации истории).

## 3. Автообновление по кнопке (канал stable)

1. После первоначальной установки `FirstInstall` дальнейшие обновления канала `stable` доставляются напрямую с собственного защищённого HTTPS-сервера Golden Breeze (доступ к GitHub для обновлений не нужен).
2. Программа проверяет криптографическую подпись манифеста обновления (**Ed25519**, файл `.sig`) и контрольные суммы пакетов. Пока обновление загружается в фоне, ход загрузки показан в нижнем блоке левого меню (точка на кнопке ⓘ при свёрнутом меню) без белого оверлея; когда пакет готов, один раз за сессию в левом нижнем углу появляется компактное напоминание с кнопками **«Обновить»** и **«Позже»**. Обновлением можно управлять и из окна **«О программе»**.
3. Штатный перезапуск проходит бесшовно, без промежуточных служебных окон; служебное окно появляется только при занятых файлах, долгой проверке, откате или ошибке. Если активно рабочее ядро агента или идёт операция, программа дожидается безопасного завершения. Если папку программы удерживает сторонний процесс, окно обновления покажет его имя и продолжит установку после освобождения папки.
4. Пользовательские профили, счета и видимая история диалогов сохраняются. При сбое обновления программа восстанавливает предыдущую версию и формирует короткий обезличенный технический отчёт (без путей с именем пользователя, номеров счетов, ключей и содержимого баз). Если приложение не запустилось или обновление завершилось сбоем, сервисное окно предлагает отправить обезличенный диагностический отчёт одной кнопкой (позже это можно сделать и в окне **«О программе»**) и возвращает код обращения `#GB-XXXXXX`, который стоит указать в обращении; при отсутствии связи отчёт сохраняется в файл. Личные пути, имена пользователей, ключи, пароли и номера счетов скрываются автоматически.
5. **Совместимость данных начиная с `v0.18.0-alpha`:** обновление переводит локальные данные программы в новый формат. После него версии `0.17.3-alpha` и более ранние не открывают эти данные. Чтобы вернуться к такой версии, восстановите резервную копию, сделанную до обновления, через окно восстановления; не переносите данные между версиями вручную.
