# Golden Breeze

![Golden Breeze — Control Desk. Рабочее место для торговых агентов.](assets/brand/golden-breeze-banner.svg)

**Рабочее место для управления торговыми агентами и подключёнными счетами.**

Golden Breeze объединяет торговые счета, стратегии, настройки подключений и наблюдение за работой в одном приложении для Windows. Пульт управления — Control Desk — помогает видеть состояние агентов, результаты проверок и журнал выполнения.

[Выпуски и загрузки](https://github.com/nikolaykazakovvs-ux/golden-breeze-releases/releases) · [Первый запуск](docs/first-start.md) · [Вопросы и поддержка](https://github.com/nikolaykazakovvs-ux/golden-breeze-releases/issues)

> **Ранняя версия · Alpha.** Приложение развивается; общий установщик ещё не опубликован. Доступные функции, подключения и ограничения определяются заметками к конкретному выпуску.

## Всё в одном рабочем пространстве

- **Агенты и стратегии.** Пульт управления показывает состояние агентов и условия их готовности к запуску.
- **Счета и подключения.** Настройки рабочего пространства объединяют подключения к торговой платформе и выбранному провайдеру искусственного интеллекта (ИИ).
- **Контроль выполнения.** Состояние работы, результаты операций и журнал помогают следить за происходящим и разбирать причины остановок.

Система ИИ-агентов развивается поэтапно. Тип подключаемого счёта — demo или real — и готовность агента к исполнению заявок проверяются отдельно. Поддержанные подключения и разрешённые режимы будут указаны в каждом выпуске.

## Скачать и начать работу

**Проверенный установщик для общей раздачи пока не опубликован.** Когда он будет доступен, его можно будет получить в [разделе Releases](https://github.com/nikolaykazakovvs-ux/golden-breeze-releases/releases). Там же будут описание изменений, известные ограничения, контрольная сумма и сведения о подписи издателя.

Приложение предназначено для **Windows x64**. Поддержанные версии Windows, требования к торговому терминалу и провайдеру ИИ будут указаны вместе с установщиком. Архивы **Source code**, автоматически создаваемые GitHub, содержат материалы этой страницы и не являются установщиком Golden Breeze.

[Установка и первый запуск →](docs/first-start.md)

Инструкция пока готовится к первому внешнему выпуску. Перед установкой сверяйте её с требованиями и ограничениями выбранной версии.

## Как приходят обновления

После первоначальной установки механизм обновлений использует собственный сервер Golden Breeze. Программа показывает доступное обновление; применение начинается по кнопке **«Обновить»** и ожидает безопасного состояния приложения. Для получения дальнейших обновлений GitHub-аккаунт не нужен.

Проверка установки и последовательных обновлений общего пользовательского канала входит в подготовку первого внешнего выпуска. Доступность конкретного обновления и его изменения описываются в заметках версии.
