# Golden Breeze

Golden Breeze — приложение для Windows с единым рабочим пространством для торговых счетов и стратегий.

В одном окне: Пульт управления, настройки подключений, состояние выполнения и журнал работы. Проект находится на стадии alpha; система ИИ-агентов развивается.

![Пульт управления Golden Breeze с тестовым агентом](assets/screenshots/control-desk.png)

*Пульт управления, 6 сентября 2026 года. Тестовый агент без подключённого счёта.*
