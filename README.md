# Golden Breeze

**Приложение для Windows с единым рабочим пространством для торговых счетов, стратегий и развиваемой системы ИИ-агентов.**

Golden Breeze объединяет Пульт управления, настройки подключений, состояние выполнения и журнал работы. Агентное ядро развивается поэтапно; завершённые функции описываются в заметках к конкретным выпускам.

## Состояние проекта

Проект находится на стадии **alpha**. Этот репозиторий пока закрыт: здесь готовятся страница проекта, пользовательская документация и установщики для будущей раздачи. Открытие доступа будет отдельным решением владельца.

Исходный репозиторий приложения остаётся приватным. Внутренние сборки оператора не предназначены для общей раздачи.

## Скачивание

**Установщик в этом репозитории ещё не опубликован.** После проверки выпуска он появится в [разделе Releases](https://github.com/nikolaykazakovvs-ux/golden-breeze-releases/releases) вместе с описанием изменений, известными ограничениями, контрольной суммой и требованиями к установке. Сейчас в Releases нет готового установщика; ссылка ведёт на список выпусков и не обещает наличие файла.

Ссылка скачивания будет вести на выбранный проверенный выпуск.

## Установка и первый запуск

Установщик предназначен для Windows x64. Для первой установки понадобится поддерживаемая выпуском версия Windows; точные требования к Windows, торговому терминалу и выбранному провайдеру ИИ будут опубликованы вместе с проверенным выпуском. Установка и обновление должны проходить без среды разработчика на компьютере пользователя. Подтверждённой подписи Windows Authenticode у установщика пока нет; подпись манифеста обновления её не заменяет.

Черновик пользовательского порядка: [установка и первый запуск](docs/first-start.md). До приёмки конкретной сборки эта инструкция не означает готовность установщика к раздаче.

## Обновления

После первоначальной установки программа получает доступные её каналу обновления с сервера Golden Breeze на нашем VPS. Она показывает уведомление; применение начинается по кнопке **«Обновить»** и ждёт безопасного состояния приложения. Для обновлений GitHub не требуется.

Для дальнейших обновлений пользователю не нужны GitHub-аккаунт, SSH-ключи, токены разработчика или 1Password. Внутренний канал оператора и общий пользовательский канал обслуживаются отдельно.

## Демо-счёт и исторический прогон

Брокерский demo-счёт использует виртуальные средства, но обращается к торговой платформе и её рыночным данным. Исторический прогон стратегии или симулятор — отдельный режим проверки. Наличие demo-счёта само по себе не означает, что агент уже настроен на исполнение заявок: режим агента и готовность подключения проверяются отдельно.

Доступные режимы первой внешней версии и правила пилота будут указаны в её заметках. Результаты на demo или исторических данных не являются обещанием результатов на реальном счёте.

## Перед первым внешним выпуском

- Опубликовать точный перечень принятых функций и поддержанных подключений.
- Добавить скриншоты проверенной сборки на демонстрационных данных.
- Завершить инструкцию первого запуска и проверить её на чистом ПК.
- Указать условия использования, лицензионные сведения и способ сообщить об ошибке.
- Проверить скачивание установщика, его подпись и последующее обновление самой программой.

Планы развития будут обозначаться отдельно от подтверждённых возможностей выпущенной версии.
